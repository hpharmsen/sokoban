# sokoban
Sokoban implementation using Gridworld array backed grid

## Running
Requires [uv](https://docs.astral.sh/uv/) and a checkout of
[gridworld](https://github.com/hpharmsen/gridworld) next to this folder (`../gridworld`).

```
uv run main.py
```

Keys: arrows to move, click a cell to walk there, backspace to undo a push,
`r` restart level, `s` save, `l` load, `f` full screen, `q` quit.
